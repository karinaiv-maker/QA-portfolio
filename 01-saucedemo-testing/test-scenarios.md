# Test Scenarios – SauceDemo

## 1. Login
- Verify login functionality with valid and invalid credentials.

## 2. Products
- Verify products are displayed correctly.
- Verify product details can be opened.

## 3. Add to Cart
- Verify products can be added to the cart.
- Verify the cart updates correctly after adding a product.

## 4. Remove from Cart
- Verify products can be removed from the cart.
- Verify the cart updates correctly after removing a product.

## 5. Product Sorting
- Verify products can be sorted by name from A to Z.
- Verify products can be sorted by name from Z to A.
- Verify products can be sorted by price from low to high.
- Verify products can be sorted by price from high to low.

## 6. Checkout
- Verify the user can proceed from the cart to checkout.
- Verify the checkout information form accepts valid customer data.
- Verify required checkout fields are validated.

## 7. Checkout Overview
- Verify the order summary displays the correct product information.
- Verify price and delivery information are displayed correctly.

## 8. Complete Order
- Verify the user can successfully complete an order.
- Verify an order confirmation message is displayed.

## 9. Navigation Menu
- Verify the All Items option works correctly.
- Verify the About option redirects correctly.
- Verify the Logout option logs the user out successfully.

## 10. Reset App State
- Verify Reset App State clears products from the cart.
- Verify the product buttons return to "Add to cart" after resetting the application state.
